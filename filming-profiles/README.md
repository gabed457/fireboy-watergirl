# Current filming profile

`live-state/profile.json` is the active coordinate-based profile. It contains a general system prompt, two skills, and three guardrails. No object coordinates or room-specific routes are encoded. The live scene provides both players and object positions for each decision.

The app preserves your selected model, effort, and master Skills & guardrails switch. Changes apply on Stop / Start. Reset to clean baseline restores the original short Watergirl role prompt with no skills or guards.

Earlier profiles are archived outside this folder for recovery. They are not loaded by the application.
